
# Placement Portal Application

A full-stack placement portal web application built with Flask, SQLAlchemy, and SQLite that enables students to apply for jobs, companies to manage placement drives, and admins to monitor the recruitment process.

## Description
A web-based placement portal where:

Admin manages students and companies.

Companies create placement drives.

Students apply for jobs.

## Technologies Used
- Flask
- SQLite
- HTML
- CSS
- Bootstrap
- Jinja2
